隐私政策

一、概述

极简背单词（以下简称“本应用”）是一款运行于 Windows 桌面的离线背单词工具。我们尊重并保护你的隐私，本政策说明本应用在数据处理方面的做法。

二、我们收集的数据

本应用不收集、不上传、不共享任何个人数据。
  • 本应用无需注册或登录，不要求提供姓名、邮箱、手机号、账号等身份信息。
  • 学习记录（包括当前选择的词库、单词熟度标记、已删除单词、学习进度与统计等）仅保存在你本机设备上，不经过任何服务器，也不会被上传。
  • 词库数据随安装包内置，应用不联网拉取外部词库。
  • 语音朗读使用操作系统内置的语音合成（TTS）能力在本机完成，不会把单词或文本发送到外部服务。

三、第三方 SDK 与网络请求

  • 本应用不接入第三方统计分析、广告、推送、支付、社交或追踪 SDK。
  • 首版本应用不发起用于数据收集的外部网络请求。若未来版本新增检查更新、云同步、账号或订阅等联网功能，我们会在更新本政策时单独说明其数据用途与范围。

四、数据的存储、导出与删除

  • 你的学习数据保存在本机应用数据目录中，由应用自行管理。
  • 你可以在应用内随时使用“导出 JSON”备份全部学习数据，使用“导入 JSON”恢复数据，或使用“清空数据”删除本机全部记录。
  • 卸载本应用时，请按系统提示确认是否一并删除本机应用数据；如需彻底清除，可在卸载后手动删除对应数据目录。

五、权限使用说明

  • 本地文件读写：仅用于导入 / 导出 JSON 备份文件，由你主动选择文件位置，应用不访问其他目录。
  • 系统语音合成：仅用于朗读单词，在本机完成。
  • 本应用不申请麦克风、摄像头、位置、通讯录、相册等与功能无关的设备权限。

六、儿童隐私

本应用为通用语言学习工具，不面向特定低龄群体收集个人信息；由于应用不收集任何个人数据，亦不存在向未成年人收集信息的情形。

七、政策更新

我们可能根据功能调整更新本政策。政策更新后，生效日期与更新日期将在页面顶部注明；涉及数据处理方式的重大变更时，我们会在应用内或发布说明中予以提示。
